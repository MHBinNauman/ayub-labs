## Notes

- `logo-emblem.png` is too small for anything but a fallback. Use `logo-emblem-192.png`.
- `logo-wordmark.png` includes address text baked into the image.
- No vector logo exists yet (`brandTokens.logo.vectorAvailable` is `false`). Replace these PNGs when the client supplies an AI/SVG/PDF.
- The badge paths match `registrations[].logo` in `site-data.ts`. Show a badge only on the branches listed in that entry's `appliesTo`.

## Icons and Open Graph images

All derived from `logo-emblem-192.png`:

- `src/app/icon.tsx` (32px tab icon), `src/app/apple-icon.tsx` (180px, on white) and `src/app/icons/maskable-512/route.tsx` (manifest icon, on navy) are generated at build time, so they follow this file automatically.
- `src/app/favicon.ico` cannot be generated by Next.js. Rebuild it with `python scripts/generate-favicon.py` whenever the emblem changes.
- Open Graph images (`src/lib/og-image.tsx`) also use the emblem, plus `src/assets/fonts/montserrat-latin-700-normal.woff` (SIL OFL, see `OFL.txt` there).

The 512px icon is upscaled from the 192px emblem. Replace the emblem with a larger export once a vector logo exists.
